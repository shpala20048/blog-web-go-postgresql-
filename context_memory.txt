ТАБЛИЦЫ БД:

- users: id, firebase_uid UNIQUE, email, display_name, email_verified, last_login, created_at, updated_at

GO BACKEND (C:\Projects\Go\1\blog\go\):
- cmd/main.go: точка входа
- internal/model/auth.go: модели User, Session, AuthLog, RateLimit, FirebaseUser
- internal/repository/auth.go: работа с БД (CREATE USER, sessions, логирование)
- internal/service/auth.go: Firebase + бизнес-логика (верификация токена, login, logout, rate limiting)
- internal/handler/auth.go: API эндпоинты (/auth/login, /auth/logout, /auth/verify, /auth/reset-password, /auth/me)
- internal/middleware/auth.go: защита роутов (RequireAuth)
- firebase-config.json: credentials для Firebase (нужен Private Key)

API ЭНДПОИНТЫ:
- POST /auth/login - вход (принимает id_token от Firebase, возвращает сессию)
- POST /auth/logout - выход
- GET /auth/verify - проверка сессии
- POST /auth/reset-password - сброс пароля через Firebase
- GET /auth/me - данные пользователя (защищённый роут)
- POST /api/posts - создать пост
- GET /api/posts - список постов
- GET /api/posts/:id - один пост
- PUT /api/posts/:id - обновить пост
- DELETE /api/posts/:id - удалить пост
